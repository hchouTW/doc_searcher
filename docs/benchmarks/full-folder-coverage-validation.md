## Operational limits

Tesseract and its languages remain external runtime dependencies in frozen builds. Semantic dependencies require the optional extra/build flag and a local model. OCR can be partial or unsuccessful and does not promise perfect character recognition. Embedded Office objects/threaded comments and calculated results without saved caches remain explicit omissions. Folder events reconcile the owner's full scope rather than only the changed subtree; periodic scans and large queues can delay updates. Model startup/inference is not a hard five-second operation.
